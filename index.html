OBIX POCKETSHIELD

เครื่องมือความปลอดภัยที่ทำงานในเครื่องคุณ
ประมวลผลในเบราว์เซอร์เท่านั้น รหัสผ่าน ไฟล์ และ URL ของคุณไม่ถูกส่งไปยังเซิร์ฟเวอร์ใด ๆ และไม่มีการเก็บข้อมูล

เลือกเครื่องมือ

ทุกเครื่องมือทำงานจริงในเครื่องของคุณ

สร้างรหัสผ่าน

ใช้ crypto.getRandomValues และตัดอคติการสุ่มด้วย rejection sampling

เข้ารหัส AES-256-GCM

Web Crypto API + PBKDF2-SHA256 (600,000 รอบ) สุ่ม Salt และ IV ใหม่ทุกครั้ง

หากลืมรหัสผ่าน จะกู้ข้อมูลไม่ได้ เราไม่เก็บรหัสผ่านหรือคีย์

Hash และตรวจความถูกต้องของไฟล์

SHA-256 / SHA-384 / SHA-512

ตรวจลิงก์ก่อนเปิด

วิเคราะห์ตามกฎพื้นฐานในเครื่อง ไม่เปิดลิงก์ ไม่ส่งไปที่ใด

JWT Inspector

ถอดรหัส Header และ Payload เท่านั้น

การถอดรหัสไม่เท่ากับการยืนยันลายเซ็น เครื่องมือนี้ไม่ได้ตรวจลายเซ็น จึงไม่ยืนยันว่า Token ถูกต้องหรือปลอดภัย

Security Headers

วาง HTTP Response Headers ของเว็บไซต์ที่คุณมีสิทธิ์ตรวจสอบ ไม่มีการส่ง Request ใด ๆ

เครื่องมือนักพัฒนา

Base64, URL, HTML entity, JSON, UUID, เวลา

Safe Cyber Lab

ระบบจำลองในแอปเท่านั้น ไม่ส่งข้อมูลออกนอกเครื่อง และไม่รันโค้ดที่คุณพิมพ์

SQL Injection

ลองใส่ชื่อผู้ใช้ admin' -- ในโหมดไม่ปลอดภัย แล้วสลับเป็นโหมดปลอดภัย

Cross-Site Scripting (XSS)

ลองใส่ <img src=x onerror=alert(1)> ระบบจะแสดงเพียงว่าโค้ดจะถูกรันหรือไม่ โดยไม่รันจริง
